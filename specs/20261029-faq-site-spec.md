## 背景・目的

`qa.md` に英語で記載されているFAQコンテンツを、日本語のFAQサイトとして公開する。
バックエンド不要で、ブラウザで直接開くだけで利用できるHTMLファイルを作成する。

## 現在の挙動

FAQは `qa.md` にMarkdown形式・英語で記載されているのみで、Webサイトとして閲覧できない。

## 期待する挙動

- `index.html` をブラウザで開くと日本語のFAQサイトが表示される
- `qa.md` の全FAQ項目（4カテゴリ・16Q&A）を日本語で表示する
- アコーディオン式で質問をクリックすると回答が開閉する
- キーワード検索ボックスで質問・回答をリアルタイムにフィルタできる
- カテゴリ絞り込みタブ（「すべて」を含む5タブ）でカテゴリを絞り込める

## 対象範囲・対象外

### 対象範囲

- `index.html` の新規作成（CSS・JavaScriptをすべてインラインで含む単一ファイル）
- `qa.md` のFAQコンテンツの日本語翻訳・HTMLへの組み込み

### 対象外

- サーバーサイド処理・APIエンドポイント
- ビルドツール・フレームワークの導入
- `qa.md` 本体の変更

## 利用者・影響システム

- 影響システム: なし（スタンドアロンHTMLファイル）

## 主な仕様

| # | 機能 | 詳細 |
|---|------|------|
| 1 | FAQコンテンツ表示 | `qa.md` の全16項目を日本語に翻訳してHTMLに埋め込む |
| 2 | カテゴリ分類 | 全般 / 使い方 / 高度な機能 / トラブルシューティング の4カテゴリで表示 |
| 3 | アコーディオン | 質問クリックで回答を開閉（初期状態：全折り畳み） |
| 4 | キーワード検索 | テキストボックス入力でリアルタイムフィルタ（質問・回答両方を対象） |

## 制約・非機能要件

- 純粋なHTML / CSS / JavaScript のみ（外部ライブラリ・フレームワーク不使用）
- 単一ファイル `index.html`（CSS・JSをインラインで含む）
- レスポンシブ対応（PC・スマートフォン）
- モダンブラウザ対応（Chrome / Firefox / Safari / Edge 最新版）

## UI・画面仕様

### 対象画面

FAQトップページ（単一ページ）

### 画面構成・表示項目

```
[ヘッダー]
  - サイトタイトル: "Bob FAQ"
  - サブタイトル: "よくある質問"

[検索ボックス]
  - プレースホルダー: "キーワードで検索..."

[カテゴリ絞り込みタブ]
  - すべて | 全般 | 使い方 | 高度な機能 | トラブルシューティング

[FAQリスト（カテゴリ別）]
  - カテゴリ見出し
  - 質問（クリックで回答開閉）
    - 質問テキスト + 展開アイコン（▼/▲）
    - 回答テキスト（折り畳み時は非表示）

[0件メッセージ]
  - 検索・絞り込み結果が0件の場合に表示
```

### 操作・画面遷移

- 質問クリック → 回答の開閉（トグル）
- 検索ボックス入力 → リアルタイムで質問・回答をフィルタ
- カテゴリタブクリック → 対象カテゴリのみ表示（「すべて」で全表示に戻る）
- 検索とカテゴリ絞り込みは同時に適用される

### 表示状態

| 状態 | 内容 |
|------|------|
| 初期表示 | 全カテゴリ表示、全アコーディオン折り畳み、「すべて」タブ選択 |
| 検索中 | 入力キーワードにマッチしない項目を非表示 |
| カテゴリ絞り込み中 | 選択カテゴリ以外のセクションを非表示 |
| 0件 | "該当する質問が見つかりませんでした。" を表示 |

### 入力・バリデーション

- 検索ボックス: 特別なバリデーションなし（任意の文字列でリアルタイムフィルタ）

### デザイン要件

- カラー: IBM Blue `#0f62fe`（ヘッダー背景・アクティブタブ等）、白背景 `#ffffff`、テキスト `#161616`
- フォント: システムフォント（`-apple-system, "Segoe UI", system-ui, sans-serif`）
- シンプル・モダンなデザイン
- レスポンシブ（PC最大幅 760px 中央寄せ）
