## 背景・目的

既存の `index.html`（FAQサイト）に対して、ブランドアイデンティティの強化とユーザー体験向上のため、以下4点を追加する。

1. ヘッダー左上にBobロゴ画像を挿入
2. ロゴ画像にIBM Bob製品ページへのリンクを付与
3. テーマカラーをBob SVGのカラー（Blue→Purpleグラジェント）に変更
4. ダークテーマの追加（ライト/ダーク切り替えボタン）

## 現在の挙動

- ヘッダーにロゴ画像はなく、テキストタイトルのみ表示
- テーマカラーはIBM Blue（`#0f62fe`）単色
- ダークテーマは存在しない

## 期待する挙動

1. ヘッダー左上に `bob.svg` が表示され、クリックすると `https://www.ibm.com/products/bob` が新しいタブで開く
2. ヘッダー背景が `#0f62fe` → `#a56eff` のグラジェントになる
3. アクティブタブ・カテゴリ見出し・フォーカス色等がグラジェントテーマに更新される
4. ヘッダー右上のトグルボタンでダーク/ライトテーマを切り替えられる
5. ダークテーマの設定はブラウザセッション中は維持される（`localStorage` を利用）

## 対象範囲・対象外

### 対象範囲

- `index.html` の修正（HTML構造・CSS・JavaScript）

### 対象外

- `bob.svg` 本体の変更
- FAQコンテンツ（質問・回答）の変更
- 新規ファイルの追加

## 利用者・影響システム

- 利用者: IBM Bobハンズオン参加者
- 影響システム: なし（スタンドアロンHTMLファイル）

## 主な仕様

| # | 機能 | 詳細 |
|---|------|------|
| 1 | Bobロゴ挿入 | ヘッダー左上に `<img src="bob.svg">` を配置、高さ48px |
| 2 | ロゴリンク | `<a href="https://www.ibm.com/products/bob" target="_blank" rel="noopener">` でラップ |
| 3 | テーマカラー変更 | ヘッダー背景: `linear-gradient(135deg, #0f62fe, #a56eff)` / アクティブタブ・カテゴリ見出し色: `#6929c4`（Purple寄りに変更） |
| 4 | ダークテーマ | ヘッダー右上にトグルボタン（🌙/☀️）/ `<html>` に `data-theme="dark"` を付与して切り替え / `localStorage` でテーマを永続化 |

## 制約・非機能要件

- 追加ファイルなし（`bob.svg` はHTMLと同一ディレクトリに存在）
- 純粋なHTML/CSS/JavaScriptのみ（外部ライブラリ不使用）
- 既存の検索・アコーディオン・カテゴリ絞り込み機能に影響しない

## UI・画面仕様

### 対象画面

FAQトップページ（`index.html`）のヘッダーおよびテーマ全体

### 画面構成・表示項目

```
[ヘッダー]（グラジェント背景）
  左上: [bob.svgロゴ画像] ← クリックでIBM Bob製品ページへ
  中央: "Bob FAQ" タイトル + "よくある質問" サブタイトル
  右上: [🌙 ダークテーマ切り替えボタン]
```

### 操作・画面遷移

- ロゴクリック → `https://www.ibm.com/products/bob` を新しいタブで開く
- テーマトグルボタンクリック → ライト/ダーク切り替え（即時反映）

### 表示状態

| 状態 | 内容 |
|------|------|
| ライトテーマ（デフォルト） | 白背景・グラジェントヘッダー・テキスト `#161616` |
| ダークテーマ | 背景 `#161616`・カード `#262626`・テキスト `#f4f4f4`・ヘッダーは同グラジェント |

### 入力・バリデーション

なし

### デザイン要件

- ヘッダー背景: `linear-gradient(135deg, #0f62fe 0%, #a56eff 100%)`
- アクティブタブ背景: `linear-gradient(135deg, #0f62fe, #a56eff)`
- カテゴリ見出し色: `#6929c4`（ライト）/ `#a56eff`（ダーク）
- カテゴリ見出し左ボーダー色: `#0f62fe`（ライト）/ `#a56eff`（ダーク）
- ダークテーマ: 背景 `#161616`、サーフェス `#262626`、テキスト `#f4f4f4`、ボーダー `#393939`
